# Bienvenue à DataScIIence!
Cours de l'association DataScIIEnce pour l'année 2026-2027. Vous trouverez dans ce dossier toutes les ressources utilisées dans les formations, des exercices, des liens utiles et autres!
## Quelques astuces pour bien démarrer 
- Posez des questions!
- Soyez actifs et déterminés (certifictions en ligne, projets...)!
- Partagez aux autres ce que vous découvrez!
- Cheatsheets non fournies: Les construire soi-même, bien que chronophage, apporte plus de valeur. Au meilleur des cas, vous repasserez les notebooks au peigne fin avant d'éditer vos fiches (apprentissage en parallèle). Au pire des cas, il est possible de les générer via Claude en passant les notebooks fournis en entrée (familiarisation avec les LLM).
